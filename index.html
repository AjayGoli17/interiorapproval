A 3-minute demo story

Use Admin ⇄ Client view so the client sees changes land live.

  1. Admin: Designs → Mehta Residence → Kitchen → Upload version, then Send to client.
  2. Client Portal: Designs → Kitchen now says “Awaiting approval”. Tap Request Changes and add a comment.
  3. Admin: the Kitchen turns to “Revision” and the bell lights up. Send a new version again.
  4. Client Portal: Approve Design. Admin and Project Manager both show Approved.
  5. Client Portal: Changes → New Request (e.g. “Extra shelf in study”, ₹8,000).
  6. Admin: Site → Change requests → Approve. The portal shows it Approved, the budget goes up, and a draft invoice appears under Payments.
  7. Project Manager: mark a site task Done. Progress rises in Admin and in the portal.

Use Reset before each demo for clean data.
